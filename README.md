# shaunaliu-github.github.io
Personal website. 

## Run locally

1. Install the VS Code extension Live Server (extension id: `ritwickdey.LiveServer`).
2. Open `index.html` in VS Code.
3. Click `Go Live` in the status bar.
4. Optional: run the debug profile `Launch Chrome with Live Server`.

The workspace is configured to use `http://127.0.0.1:5500/index.html`.
